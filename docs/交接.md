一句话：DSH 插件，点选/划选对话里的英文单词看释义，划选纯英文句子翻译。离线词库，不联网，不要 API key。

## 两侧职责

宿主侧只是一台静态文件服务器，浏览器侧持有全部查询能力。查词零网络。

**宿主（`index.js`，698 行）**
- `inject = ['webServer']`，可选探测 `llm`（拿不到就只是不能翻译）
- 一条 prefix 路由 `/api/dsh-hover-dict`：`meta.json`、`dict.dat`、`wordroot.dat`（gzip）、`health`、`translate`（POST）
- 白名单 + 启动时扫 `data/packs/`，绝不拼路径（防穿越）
- Config 只有三项：`dataDir`、`enabled`、`maxBytesPerFile`

**浏览器（`client.js`，构建产物 191.2 KB）**
- 源码在 `client/src/`，15 个模块，用 `client/build.mjs` 拼接，**无打包器**
- 挂两个 slot：`shell.overlay`（高亮+浮层+卡片）、`settings.section`（order 26，标签「英语翻译」）

## 两条不能破的红线

**1. 不改正文 DOM。** 不许把单词包成 `<span>`。流式输出每秒重渲染，包了就会丢节点、和 React diff 错位、破坏复制。做法是：
- 反查坐标：`caretRangeFromPoint` / `caretPositionFromPoint` 拿到 `{node, offset}`
- 量矩形：`Range.getClientRects()`，跨行必须逐段画
- 画：渲染进 `shell.overlay`，`position: fixed`，与正文是兄弟关系

**2. Config 用 schemastery。** 普通对象会让插件**静默不激活**，报错是 `Cannot read properties of undefined (reading 'validate')`。

## 配置分两处

判据是「改了要不要重启」：

- 要重启 → 宿主 `Config`（`index.js`）
- 不要 → `localStorage` 的 `dsh-hover-dict:ux`（`client/src/config.js`，含 `clampTiming` / `clampAppearance` 越界直接夹）

界面参数别塞进 Config，改 50ms 悬停延迟不该逼用户动 profile。

## 数据

`data/` 三件，随包分发，构建脚本在 `scripts/`（ECDICT MIT + Tatoeba CC-BY-2.0-FR）。

- `dict.dat` 3.3 MB，20,499 词条
- `wordroot.dat` 465 KB，6,374 个词根分析
- `meta.json` 计数 / 来源 / 许可 / 压缩档位；8,960 个词带双语例句

词条是**变长数组**，槽位固定：

| 槽 | 字段 | 说明 |
| --- | --- | --- |
| 0 | senses | `SenseGroup[]`，按中文义项数降序，最重要的词性在前 |
| 1 | tags | 空格分隔，如 `"cet4 cet6 ky"`，无则 `null` |
| 2 | frq | ECDICT 词频序号，0 记 `null` |
| 3 | forms 或 examples | **多态**：有变位写字符串，没有而例句挤上来写数组，靠 `typeof` 判 |
| 4 | examples | `[英文, 中文][]`，可选 |

槽 3 多态是历史包袱，`docs/架构.md` §4.2 有解释。改动这里先读那一节。

## 已知坑

- 翻译走宿主 `llm` 服务，不是 `translator` bundle（那个默认关闭）。不要改回去。
- 查词范围限死在对话正文，输入框与模型选择器不触发（`dffe3840` 修的）。
- 修完整词条里点星标没反应见 `docs/FIXES.md`（6d79a3d8）。
- `cordis.patch.yml` 只插一行、不写 config。写死了用户覆盖就得连这里一起改。
