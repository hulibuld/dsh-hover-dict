在 DeepSeek 里读英文，点一下词就看到它什么意思。不会的词收进生词本，正文里自动标红，按间隔重复刷。

## 装

命令一行，装完重启 DSH，插件不走热重载。重启后不用找开关，划词就能用。

## 能查什么

单击一个英文词，或者双击，或者左键划选一个词，旁边浮出小卡片：词性、中文释义、考纲标签。

划选一段纯英文，给中文翻译。中英混排的不翻，汉字超过 10% 就跳过，只提示一句，不会静默没反应。

点一下浮层，展开大卡片：全部义项、英英释义、词形变化、同根词、词根词缀、双语例句。

范围只算对话正文。代码块、行内代码、工具调用卡片里的英文都能查，那些地方恰恰最常要查，变量名、命令、报错信息都在里面。输入框、右下角的模型选择器、侧栏和设置页不响应，在那些地方点一下是想定位光标或开菜单，弹词典只会碍事。

结果不会自己消失。点浮层外面、按 Esc、重新选别的，三种才关。

选中的词不加底色也不加边框。

词头旁边有个 🔊，点一下用浏览器自带的声音念出来，再点一次停。念不准就去查发音词典 —— 这个功能是让你顺手确认读音，不冒充标准音标。

音标不单独成字段。导入的词如果自带音标，会拼在释义前面跟着一起显示。

## 生词本

卡片和浮层右上角都有星标，点亮表示这个词已经在里面了。

一个词和你背过的词是什么关系，用颜色分。红的是这个词本身在生词本里，它的变位也算，收藏了 run，ran、running、runs 都标红。蓝的是同一个语义词族里但没收藏，查 care 时 careful、careless、carer 标蓝。

同根词按派生规则判断，不看字符串像不像。care 和 career 前缀一样，但没有词源关系，不会连在一起。

生词本存在 DSH 的本地存储里，换浏览器、清缓存都不丢。

### 三个状态，加一个「还没学」

每个词有自己的状态，一眼就知道掌握到什么程度：

| 状态 | 什么意思 |
| --- | --- |
| 未学 | 刚收进来，还没复习过 |
| 不认识 | 复习时标了「不认识」 |
| 记错 | 复习时标了「记错」——见过，但想岔了，跟完全空白是两回事 |
| 已掌握 | 复习间隔已经拉到 21 天以上，或者你自己手动标了 |

界面上用四种颜色分：灰、红、橙、绿。在管理台里每个词都能直接改状态。

### 到点会自己回来找你

复习间隔按简化的 SM-2 算，不搞玄学：

- 标「不认识」→ 10 分钟后再来一次，间隔清零
- 标「记错」→ 间隔减半，最少 1 天
- 标「认识」→ 1 天、3 天、然后按难度系数往上翻倍，最多 365 天

难度系数在 1.3 到 3.0 之间，答错就降，答对慢慢升。所以一个总记不住的词会一直贴着你，真背下来的词会自己退到 20 天以后。

「已掌握」的门槛是间隔跨过 21 天，不是答对一次就算 —— 答对一次就叫掌握，那这个词就没意义了。

生词本里所有词共用一套复习队列，不管你从哪本书收的。

### 多本词书

可以建多本词书分开管（比如「四级词表」「论文里遇到的」），但**同一个词只存一份**。同一个词同时出现在两本书里，只是多记一个归属，复习进度共用 —— 不会出现两本书各刷一遍的情况。

删词书不删词：书里的词会退回「默认生词本」，一个都不会丢。「默认生词本」是内置的，删不掉也改不了名，划词收藏一律进它。

## 词根词缀

卡片里给一个词的拆解。biography 是 bio 生命加 graph 写，rewrite 是 re- 再，careless 是 -less 没有。

6,374 个词有分析，占词库 31%。宁可漏也不误判：拆完要过四道闸门，词干得真实存在，释义要有语义重叠，独立基础词不硬拆，人工确认的假拆分进排除表。所以 understand 不会被拆成 under- 加 stand。

## 设置页

设置左侧导航那一列会多出「英语翻译」，排在「技能」和「费用」之间。点开是**五个页签**。

只有这一个入口，不另外挂详情页，也不挂侧边栏图标。

### 页签一：生词本

顶上四个数字：总词数、今日到期、已掌握、连续学习天数。下面一条四色占比横条和 30 格打卡格子，深色代表那天复习得多。

再往下是词表，一行一个词，能看到状态、下次复习时间、来源（划词/有道/导入/手动）。点词头展开，看词库释义、例句、查过几次。

词多也不怕：**每页 50 行，能翻页**。以前只显示前 120 个，后面的要导出才看得见，现在全部能翻到。

工具行有搜索（词头或释义都能搜）、状态筛选、词书下拉、排序（最近添加/最久未复习/字母序）。

批量操作：勾上几个词，可以一次转成「已掌握」、一次移进某本词书、或一次移出。移出要点两下确认，不会误删。

导出三种：txt 一行一词、CSV 带状态和释义、JSON 完整备份（含状态和复习进度，能在导入页还原）。

### 页签二：复习

从到期的词里出题，卡片正面是词，点一下或按**空格**翻面看释义。

三个按钮对应键盘 **1 / 2 / 3**：

- `1` ✗ 不认识
- `2` ↻ 记错
- `3` ✓ 认识

方向能切「英 → 中」和「中 → 英」。中 → 英只出有释义的词，词库里查不到又没写备注的词不会拿来考你。

也能筛「只刷不认识」「只刷记错」，或只刷某一本词书。

今天没到期的词会直接告诉你「今天没有到期的词」，还想过瘾可以「提前复习最早到期的 20 个」。

一轮结束给你正确率和三态分布，可以再来一轮。按 Esc 退出。

### 页签三：导入

**两步走，先看清再加，不会糊里糊涂写进去。**

第一步：粘贴内容，或者点「从文件读取」选一个 `.txt` / `.csv` / `.tsv` / `.json`。选好目标词书，或当场新建一本。

第二步：点「解析预览」，出来一张表，每行告诉你这个词是**将新增**、**已存在**、还是**词库未收录**，旁边是能抓到的释义。顶部有汇总：「识别 X 个词：新增 A、已存在 B、未收录 C」。

认的格式：一行一词、`apple,ˈæpl,n. 苹果` 这种 CSV、Tab 分隔的 TSV、本插件导出的 JSON 备份、有道导出的整段。有道那种带 `/音标/` 的也认。

跳过的行不会悄悄消失：底下有一行「跳过 N 行（展开看原因）」，点开能看到每行是空行、注释、还是压根不是英文单词。

觉得没问题，再点「确认导入」，这一步才真正写库。

JSON 备份还原也走这里：把备份文件读进来，状态、复习进度、备注、所属词书全都跟着回来。

### 页签四：外观与交互

浮层释义条数、卡片宽度、中文占比阈值、考纲标签开关、翻译接口、词库管理，都在这儿。

再加上生词着色的一组开关，见下面「生词着色」一节。

### 页签五：有道同步

把有道词典收藏夹里的词一次性抓进生词本。见下面「有道同步」一节。

## 生词着色

正文和思考内容里，**生词本里还没掌握的词会标出来**，一眼看见自己之前不会的词。

**只改字本身的颜色** —— 不加底色、不加下划线、不垫色块。默认用的就是你在这套界面里
见过的那个「报错红」（工具调用出错时红字用的同一个颜色 token），所以亮暗主题下都跟着变。

在「外观与交互」页签能改：

- 颜色：默认「跟随主题错误红」，也可以钉死成某个固定色（六个预设，或自己挑）
- 已掌握的词要不要也淡淡标一下（默认不标 —— 都背下来了还刺眼干嘛）
- 一个总开关，关掉就完全不变色

改完立刻生效，不用重启。

**两个细节值得说**：

1. **不改正文的任何一个字**。用的是浏览器原生的 CSS Custom Highlight API：把「哪几个字符区间要换颜色」交给浏览器，渲染时它自己上色。正文 DOM 一个节点、一个属性都没动。所以流式输出不错位、复制粘贴不会多出乱七八糟的符号、划词查词也不受影响。
2. **滚动时颜色跟着字走**。因为颜色是浏览器在渲染文字时上的，不是我们另外画一层再算坐标 —— 上下滑的时候不可能出现「颜色留在原地、字跑了」的错位。

## 有道同步

不想一个个手动加词的话，可以把有道词典的收藏夹整个搬过来。

做法是让插件借用你浏览器里的登录态，不需要把有道账号密码交给插件（密码这东西，不给任何人最安全）。

四步：

1. 浏览器打开 `dict.youdao.com` 并登录
2. 按 `F12` → 切到 **Network（网络）** → 刷新页面 → 点列表里第一个请求
3. 在右侧 **Request Headers** 里找到 `Cookie:`，把冒号后面那一整段复制下来
4. 粘进插件「有道同步」页签的输入框，点「保存并验证」

验证通过会显示你的昵称和词数，然后点「一键抓取收藏夹」，抓完告诉你「新增 X 词，已存在 Y 词」。

Cookie 只存在你自己电脑的插件目录里，不进配置、不回显给界面、发包也不带它。随时可以点「清除」。

抓回来的词会带上有道那边的释义，所以就算离线词库没收录，你也能看到意思。

如果哪天有道改了接口、抓不动了，面板会明说「有道接口改版了」，并且给你手动导出的路子：在有道生词本页面全选复制，粘到「导入」页签里就行。不会让你对着一个转圈的进度条干等。

## 词库

自带三个，随包分发，完全离线。

核心词库 20,499 个考纲核心词，中考、高考、四六级、考研、托福、雅思、GRE 都在里面。词根词缀库 6,374 个词的拆解。双语例句库 8,960 个词的中英对照例句。

自己加词库：文件放进 `data/packs/`，重启 DSH 后自动加载。支持两种格式。ECDICT 的 CSV，只要有 `word` 和 `translation` 两列就能用，`definition` 和 `tag` 可选。或者跟 `dict.dat` 同构的 JSON，键是词头，值是槽位数组。

文件名只能是小写字母、数字、连字符，加 `.dat` 或 `.csv`。

词库是构建期产物，随包已经给好了。要换语料或者改筛选口径才需要重跑构建脚本。
